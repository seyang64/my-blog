# Hello World

Welcome to my blog! 👋 This site is built with **plain HTML, CSS, and JavaScript** — no frameworks, no build step.

Every post is just a Markdown file in the `posts/` folder. The browser downloads it, converts it to HTML, and shows it here.

## How to write a new post

1. Create a file like `posts/my-new-post.md`.
2. Add front matter at the top (title, date, tags, description).
3. Add an entry for it to `posts/posts.json`.
4. Refresh the page. That's it!
